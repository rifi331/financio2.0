# v2.8.0 Features Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Recurring transactions, budget alerts, an edit command, month-over-month report comparison, per-chat AI conversation context, and a small duplicate-check fix.

**Architecture:** All features extend the existing dispatcher/store pattern. One new daily ticker goroutine in `cmd/financio/main.go` drives recurring inserts and budget alerts. Conversation context is an in-memory per-chat ring buffer injected into `ParseEntry`. Report comparison reuses the existing expense totals with a second queried month.

**Tech Stack:** Go 1.25, pgx/v5, existing packages only (no new deps).

**Spec:** docs/BRIEF.md + user requests 2026-10-18 (this session).

## Global Constraints

- Single replica, long polling, outbound-only (BRIEF Runtime contract).
- Parameterized SQL only; model output never becomes SQL text (BRIEF).
- Secrets never committed; new env vars optional with sane defaults.
- All user-facing bot text bilingual EN/ID where a language is known; commands are English-only (consistent with existing /prompt, /param, /budget).
- Test fakes in `internal/bot/bot_test.go` (fakeStore, fakeAI, fakeSender) are extended, never bypassed.

## Review Focus

- Recurring insert on months where `day_of_month > days_in_month` (31st in Feb) must not loop or double-insert: clamp to last day, `last_run` guards.
- Edit on another user's id must reply the generic not-found (no owner leakage), matching delete semantics.
- Budget alert fires once per threshold per month, not once per day.
- Conversation history must never leak one chat's messages into another chat's AI call (keyed by chatID, tested).
- Report comparison with an empty previous month renders zeros/dashes, not an error.
- `check duplicate` with `is_recap_request=false` replies the friendly hint, never a raw range error.
- Legit duplicates (MRT A→B/B→A, toll round trips, two same-price groceries same day) must never be auto-deleted or blocked — listing and hints only.
- One group's budgets/spend must never influence another group's budget lines or alerts (group-scoped everywhere, tested).
